# Scripts

- start-backend.ps1: Runs Spring Boot backend.
- start-frontend.ps1: Installs deps if needed and runs React frontend.
- start-ml-service.ps1: Creates venv if needed and runs ML service.

Usage from project root:

```powershell
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
.\scripts\start-ml-service.ps1
```
